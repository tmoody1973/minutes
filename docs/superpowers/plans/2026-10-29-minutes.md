**Goal:** Ship Minutes by Wed Nov 4, 2026, 9:00 PM ET: a phone + laptop web app that follows Milwaukee land-use files across City Plan Commission, ZND and Common Council, with readable, speaker-named meetings and a quiet Watcher, demoed on Bookends (file 260533).

## Global Constraints

- Deadline: submission in by Wed Nov 4, mid-afternoon Central; hard stop 8:00 PM Central.
- Every sentence a user sees traces to a stored record (Legistar row, transcript turn, MPROP/parcel row, or an Editor-approved generated sentence with source ids).
- Never invent Milwaukee data. Placeholders in mockups (`[Street address]`, `[Nov 10]`) are never shipped as real-looking values.
- No guessed speakers: a label gets a name only from (a) Legistar roster + transcript cue, (b) self-introduction, shown with marker text **"name as heard"**, (c) a stored manual override. Otherwise **"Speaker B"** style, re-lettered per meeting.
- Quotes: only two edits allowed: remove immediately repeated words, and apply exact corrections from Legistar records. Quote footer copy: **"Lightly cleaned machine transcript · view raw · watch this moment"**.
- Disclosure copy, verbatim, on the About page, every project and meeting screen footer, and the README: **"Built by Tarik Moody, a sitting member of the City Plan Commission. Public records only, no recommendations."**
- Tarik's votes render exactly like every other member's; no special case anywhere in code.
- Testimony position: only from the speaker's own words, with that sentence quoted; else **"Position not stated"**.
- Nothing is submitted on a user's behalf.
- Watcher: at most one alert per real change per user; on-site inbox + Resend email with unsubscribe link. Replays are labeled **"Replay of a real alert from {date}"**.
- "Watch this moment" = Granicus player at `https://milwaukee.granicus.com/player/clip/{clipId}?view_id=2&redirect=true&entrytime={seconds}`. We never host meeting audio or video.
- No disguised requests to any host (no fake User-Agent). Legistar/MPROP calls send `User-Agent: Minutes/0.1 (tarik@radiomilwaukee.org)`.
- Transcription chunks ≤ 595 s; mono 16-bit PCM WAV 16 kHz; `mode: "DIARIZATION"`.
- Muse Spark calls: `POST https://api.meta.ai/v1/chat/completions`, model `muse-spark-1.3`, `reasoning_effort: "low"`, `max_tokens` ≥ 4000 (reasoning tokens consume the budget; at 20 the reply is empty).
- Phone and laptop: real `<button>`/`<a>`, 44 px minimum targets, WCAG AA contrast. Verify at 390 px and 1440 px.
- Product code is written fresh. `gavel-slack-agent` is reference only; do not copy files.
- Secrets only in `.env.local` / Convex + Vercel env vars: `META_API_KEY`, `CLERK_*`, `RESEND_API_KEY`, `ADMIN_USER_IDS`.
- Every milestone ends with: code review, real-data verification, merge, and one line in `DEVLOG.md` (`YYYY-MM-DD · built · verified`).

## Review Focus

1. **Legistar down or slow during a sync:** stored data keeps serving, the page shows "Last updated {time}", nothing is deleted. Test in Task 1.4.
2. **An address that doesn't resolve** (typo, outside Milwaukee, a PO box): a plain "We couldn't find that address in Milwaukee's property records" message, never a crash or a random nearest match. Tests in Tasks 2.3 and 2.4.
3. **Two different people sharing a label across chunks** ("A" in chunk 3 and "A" in chunk 4): never merged unless both resolve to the same name. Test in Task 3.1.
4. **A meeting or item with no transcript or no video index:** the meeting page shows captions (labeled) or "No transcript yet", and chapters fall back to cues or are marked "not located". Tests in Tasks 3.5 and 5.1.
5. **User-typed address reaching the MPROP SQL query:** only validated tokens are interpolated (house number digits, street name `[A-Z0-9 ]`), anything else is rejected. Test in Task 2.3.

### Shared types (`lib/types.ts`, created in Task 1.2, extended in later tasks)

```ts
export type BodyKey = "council" | "cpc" | "znd";        // Legistar BodyId 1, 272, 11
export interface EventRecord { legistarId: number; bodyId: number; bodyName: string; startsAt: string /* ISO, America/Chicago */; clipId?: number; agendaUrl?: string; minutesUrl?: string; insiteUrl?: string }
export interface EventItemRecord { legistarId: number; eventId: number; sequence: number | null; matterId?: number; fileNumber?: string; title: string; actionName?: string; passed?: boolean; videoStartSec?: number; mover?: string; seconder?: string }
export interface MatterRecord { legistarId: number; fileNumber: string; title: string; typeName: string; statusName: string; introDate?: string }
export interface HistoryRecord { legistarId: number; matterId: number; date: string; bodyName: string; actionName: string; passed?: boolean; eventId?: number }
export interface VoteRecord { eventItemId: number; personId: number; personName: string; value: string }
export interface Tally { aye: number; no: number; excused: number; other: number }
export interface TimelineStep { body: string; date: string; actions: string[]; passed?: boolean; eventId?: number; eventItemId?: number; videoStartSec?: number; tally?: Tally; upcoming: boolean }
export interface Turn { eventId: number; turnKey: string /* `${chunk}:${turnId}` */; chunk: number; startMs: number; endMs: number; label: string | null /* `c${chunk}:${speaker}` */; text: string }
export interface Cue { kind: "self" | "recognized"; name: string; affiliation?: string; turnKey: string; targetTurnKey: string }
export interface SpeakerAssignment { label: string; name: string; personId?: number; source: "legistar" | "self-intro" | "manual"; evidenceTurnKey: string }
export interface ChapterPart { kind: "presentation" | "applicant" | "testimony" | "discussion" | "vote"; startMs: number; endMs: number }
export interface Chapter { eventItemId: number; startMs: number | null; endMs: number | null; located: "video-index" | "cue" | "not-located"; parts: ChapterPart[] }
export interface Change { kind: "hearing_scheduled" | "decision" | "step_added"; matterId: number; eventId?: number; at: string; sourceKey: string }
export interface Follow { userId: string; kind: "file" | "address" | "alder" | "topic"; value: string }
export interface EditorVerdict { ok: boolean; reason?: "no-source" | "unknown-source" | "evaluative" | "unsupported" }
```
